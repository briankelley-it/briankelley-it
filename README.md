## 🧑‍💻 About Me

I'm a self-taught Python and SQL developer from Cypress, Texas. I like taking messy, scattered data and turning it into clean, reliable tables people can trust. I've built backend services, REST APIs and databases, and now I'm putting that experience into **data pipelines, data modeling and cloud data tools**.

- 🎯 **Goal:** Junior Data Engineer, growing into a strong data platform engineer
- 🐍 **Main languages:** Python and SQL, every day
- 🔄 **I like:** building ETL/ELT pipelines, designing clean schemas, automating repetitive work, and tracking down *why* the numbers don't match
- 🧪 **How I work:** tests and CI on every project, version-controlled everything, clear docs, and I own what I build from source to final table
- 🤝 **What I bring:** years of fast-paced, customer-facing work taught me reliability, teamwork and staying calm when something breaks in production
- 🤖 **How I use AI:** I use Claude Code and other AI assistants to learn and move faster, then I read, test and understand every line before it ships
- 📚 **Leveling up:** Airflow DAGs, dbt models and tests, AWS data services (S3, Glue, Athena), and data quality checks
